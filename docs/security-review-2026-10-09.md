## Validation and release boundary

Focused integration tests: 125 passed. Full `npm test` passed: 285 tests passed, with two opt-in live PostgreSQL tests skipped (30 test files passed). This gate included build and live MySQL database binding generation. Source typecheck (`npx tsc --noEmit --skipLibCheck`), generated-output injection regressions (table/core/scoped syntax), YAML/action pin checks, shell syntax, and `git diff --check` passed. GitHub MySQL-service CI is required before merge. The MySQL 8 image index digest was verified live against registry-1.docker.io, including linux/amd64 support.

Security defaults change: HTTP and SQL caching both require explicit `cacheResults: true` and a trusted `cacheScope`; generic REST view exposure requires trusted `restViewAllowlist`. Migration instructions are in README. Package version remains 6.4.2 because this integration merges reviewed source; it does not publish a new npm version or prove downstream upgrades. A future release must choose its version under the project's semver policy.

Five intentional/historical product decisions remain visible: bare-string reference grammar, two trusted restUrlExpression code options, UUIDv7 timestamp disclosure, and historical named CRUD exports. These are not falsely marked fixed. Direct ORM view reads remain available for trusted server use; REST opt-in never replaces per-caller authorization or SQL allowlisting.
